## Purpose
Confirm the population starts undifferentiated (all STEM), that the cell schema is complete and uniform, and that no type-specific parameters are pre-assigned as the sole behavior path.

## What integrity looks like
If initialization already encodes specialist types, later “emergence” metrics are confounded. This check establishes a true blank slate for type discovery.
