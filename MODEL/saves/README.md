# MODEL/saves

DSC checkpoint bundles written by `/save` (F014).

- Files: `dsc_YYYYMMDD_HHMMSS.model` or a user-provided sanitized name ending in `.model`
- Format: zip containing `checkpoint.npz`, `harness.json`, `manifest.json`
- Display names only in manifests (no absolute paths)

Binary `.model` files are gitignored; this README is tracked.
