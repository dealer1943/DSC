# MODELS/worm — *C. elegans* (OpenWorm)

Offline comparison substrate from [OpenWorm](https://openworm.org/), via the [c302](https://github.com/openworm/c302) White et al. 1986 connectome CSV.

```
worm/
  openworm_c302/     # default pack for /load openworm
```

Scale sits between DSC (~128) and FlyWire (~139k): ~306 neural nodes, ~2.8k neural edges — tiny on disk, fully offline.
