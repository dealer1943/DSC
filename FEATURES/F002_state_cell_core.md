## Purpose
Define the modular computational unit of the DSC: a state cell with identity, parameters, utility, age, substrate-aware connections, and a mutable type field, **always initialized as STEM**.

## Why it is fundamental
The population is software on the substrate. Without a uniform, modular cell schema, type emergence cannot be attributed to dynamics—only to accidental architecture. STEM initialization keeps the starting distribution undifferentiated so functional types are discovered rather than prescribed.
